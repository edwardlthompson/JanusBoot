# ESP layout — `EFI/JanusBoot/`

Single source of truth on the EFI System Partition. Linux, Windows, and (later)
boot UI CRUD the same files. Paths are relative to the ESP root unless noted.

## Directory tree

```text
EFI/JanusBoot/
  settings.json          # timeout, default, theme, feature flags
  entries.json           # scanned / curated boot entries
  limine.conf            # generated by janusbootctl (may also live at ESP root)
  icons/                 # per-entry PNG icons (64 / 128 / 256 px)
  themes/
    <theme-id>/
      theme.json         # pack metadata (validated)
      background.boot.jpg|png   # compiled wallpaper (apply pipeline)
      …                  # optional chrome glyphs
  backup/
    settings-*.json      # timestamped copies before writes
    …
```

## Owned vs foreign

- **Owned:** everything under `EFI/JanusBoot/` plus Limine install paths we
  document at install time.
- **Never delete:** foreign EFI trees (`EFI/Microsoft/`, other loaders).
- Repair (later) only restores files we backed up, with confirm / dry-run.
