# ESP layout — `EFI/JanusBoot/`

Single source of truth on the EFI System Partition. Linux, Windows, and boot UI
share the same files. Paths are relative to the ESP root unless noted.

## Directory tree

```text
EFI/JanusBoot/
  BOOTX64.EFI            # installed Limine (or JanusBoot-branded) EFI binary
  settings.json          # timeout, default, theme, feature flags, repair_history
  entries.json           # scanned / curated / oneshot boot entries
  limine.conf            # generated by janusbootctl
  icons/                 # per-entry PNG icons (64 / 128 / 256 px)
  themes/
    .next/<id>/          # atomic staging during theme-apply
    last-good/<id>/      # previous live pack for rollback
    <theme-id>/
      theme.json
      background.boot.jpg
      icons/
  backup/
    <stamp>/             # settings.json + entries.json
    nvram-<stamp>/       # meta.json + dump.txt (host NVRAM export)
```

## Owned vs foreign

- **Owned:** everything under `EFI/JanusBoot/` plus documented Limine install paths.
- **Never delete:** foreign EFI trees (`EFI/Microsoft/`, other loaders).
- Repair restores backed-up owned files (and optional bootmgfw from *our* backup)
  with confirm / dry-run.

## Fixtures (dev)

`fixtures/esp/EFI/JanusBoot/` mirrors settings, entries, themes (3 packs), icons.

Built-in theme sources: `themes/{high-contrast,mint-dark,elegant-dark}/`.

Boot UI honest floor: `themes/BOOT_UI.md`.
